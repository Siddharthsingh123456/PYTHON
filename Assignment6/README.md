# Tkinter Calculator

This is a simple calculator made using Python and Tkinter.

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Clear Button

How it works:
1. User enters first number.
2. User clicks an operator.
3. User enters second number.
4. User clicks '='.
5. Program calculates and shows the result.

Variables Used:
- current_number
- first_number
- operator

How to Run:
1. Open terminal.
2. Go to project folder.
3. Run:

python calculator.py
