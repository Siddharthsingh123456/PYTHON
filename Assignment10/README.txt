
WEB SCRAPING ASSIGNMENT - PRICE TRACER APPLICATION

OBJECTIVE
This project demonstrates the use of Python web scraping techniques to collect product information from webpages.

FUNCTIONALITY
1. Fetch webpage data using Requests.
2. Extract product title.
3. Extract product price.
4. Extract image URL.
5. Download product image.
6. Convert extracted price to numeric value.
7. Compare price with a target value.
8. Handle multiple product URLs.

MY LEARNING PROCESS
- Learned how HTTP requests work.
- Learned how to inspect webpage HTML.
- Practiced using BeautifulSoup.
- Learned how to extract specific tags.
- Learned how to clean text data.
- Learned how to compare scraped data using conditions.

LECTURE / PRACTICAL OUTPUTS
The program displays:
- Current URL
- Request status
- Product title
- Product price
- Image URL
- Image download status
- Price comparison result

HOW TO RUN
1. Install required libraries:
   pip install requests beautifulsoup4

2. Run the program:
   python price_tracer.py

EXPECTED OUTPUT
- Product details displayed
- Image downloaded
- Price comparison shown
